全体の調査結果・油温と油圧の区別・未解明項目は [ロードスター実車調査まとめ](../ROADSTER_INVESTIGATION_20260915.md) を参照。

この車両（NCEC、後期エンジン/NOPRO ECU）について、ユーザー判断で候補1を「クーリングファン指令」として暫定採用。
- 要求：CAN 0x7E0、03 22 11 03 00 00 00 00。
- 応答：CAN 0x7E8、04 62 11 03 A ... の A bit2（0x04）。1=ON指令、0=OFF指令。
- 実際のモーター回転を検出した値ではない。応答なし・古い値・OBD停止/異常時は --。
- A/C OFF・エンジン運転中に水温約89〜90°Cでbit2 ON、約87〜88°CでOFFの反復を観測。実物ONの申告あり。IG ON/エンジン停止・実物OFFで、新しい応答A=0x20、bit2=0を確認。
- 19:02:51の実物OFF申告は本人が撤回しており根拠に含めない。エンジン運転中の物理停止時刻との厳密な同期照合、別車両、候補2/3は未検証。
- 候補2（1103 bit3）/3（0967 bit2）は追加リレー候補のまま。
- ファーム logger-v1-obdonly-20260915c は変更不要。CAN受信とOBD限定送信を継続。

# NCEC / EcoLogger V1 対応（2026-09-15）

対象は2005年式NCEC・MT・DSCなし、後期エンジン＋NOPRO MZ-TUNE+。
ユーザー提供 `hardware_share_20260915.md` の9月12日実測定義に基づく。
他車種への汎用定義ではない。

## 追加項目

| CAN ID | 表示・CSVチャンネル | 内容 |
|---|---|---|
| 201 | RPM / Speed | 回転数・車速 |
| 4B0 | WheelSpeedFL / FR / RL / RR | 左前・右前・左後・右後、各16bit BE |
| 200 | AccelPedal / BrakePedal | byte7のペダル絶対値、byte6 bit0 |
| 215 | AccelPedalBackup / ACRequest | byte6のペダル冗長値、byte7 bit6 |
| 231 | ClutchDisengaged | byte1 bit1（bit2とは分離） |
| 240 | WaterTemp / Throttle / IntakeTemp | 水温・スロットルバルブ・吸気温 |
| 420 | WaterTempBackup | 冗長水温 |
| 430 | FuelLevelRaw / FuelLevel | 生値と直近2秒のサンプル平均 |
| 39A | ParkingBrake | byte0 bit3 |

資料の17項目＋燃料平均1項目。既存82チャンネルへ13個を末尾追加し、全95チャンネル。
チャンネル番号とConfig保存形式を維持する。標準GNSS構成のschemaは97だが、
GNSS設定やカスタムチャンネルによって変化するため受信metadataを正とする。

アクセルペダルは `raw * 0.2144 + 30.68` のECU絶対値で、ペダル解放時も約30.68%。
スロットルバルブは `raw * 0.3938 - 0.342` を0〜100%へ制限する。
燃料は満タンを100%へ再補正しない。受信が1秒以上途切れたら平均をリセットする。
追加項目は最後の受信から500msで欠測になる。

旧 `0x240 byte0` のEngineLoad換算は根拠未確定のため削除。
標準OBD応答や明示カスタム設定によるEngineLoadは継続して扱う。
油温・油圧・舵角・未知DIDの追加取得は今回実装しない。

## 操作

EcoCapture 0.3.8で車種「マツダ ロードスター」を選ぶと追加項目が標準表示される。
冗長ペダル・冗長水温・燃料生値は表示項目設定で選択可能。SDには全項目を記録する。
保存済み表示設定は維持し、追加した項目の初期表示を適用する。
スイッチはON/OFFで表示する。欠測は `--` とする。

V1は `ncProfile=true`、`obdEnabled=false`、`toyotaSteering=false` で使用する。
NC生CANとOBD要求の排他条件を維持する。CAN送信・未知DID走査は追加していない。
クラウド送信側の許可リストにも追加チャンネルを含めるが、公開Webの画面は変更しない。

## 書き込みと確認

1. 車載CANを物理的に切り離す。
2. SD安全停止を行い `logging.safeToRemove=true` を確認する。
3. NVSを消去せず `logger-v1-ncec-20260915a` を書き込む。
4. バージョン、NC設定、OBD無効、受信専用、GPS/IMU/SDを読戻す。
5. 車載CAN再接続後、実車値・USB・CSVの同じチャンネルを照合する。

書き込み前の実車再生試験は、基板へ書いた後の受信・保存検証を代替しない。

新版書き込みと設定保持、実USBの18項目、SD末尾55行を確認済み。ブレーキ・クラッチの踏み込みと解放も照合済み。

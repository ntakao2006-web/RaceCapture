- メインマイコンは ESP32-S3-DevKitC-1ボードではなく、ESP32-S3-WROOM-1-N16R8モジュールを直接実装するフルカスタム基板と判明

- 車載CAN側に120Ω終端抵抗(R41)が実装されていた件 → ハンダジャンパーで有無を切り替え可能な方式に決定
- 外部CANバスの電源ラインを3.3Vから5Vへ変更

- USB電源入力の規格はPDではなくQC（Quick Charge）と判明。12V-1.5A（18W）にネゴシエーションし、DCDCコンバータで5V→三端子レギュレータで3.3Vへ降圧する2段構成
- 車両側の給電構成を決定：ロードスターはシガーソケット充電器でモバイルバッテリーを充電し毎回着脱で給電、エコマイレッジチャレンジ車両はシガーソケット充電器から直接給電（バッテリー分離のためクランキング対策不要）
- SDカードソケット：Molex 47219-2001（金属カバー固定式）に確定
- GNSSアンテナ：現状の回路はパッシブアンテナ仕様。将来的にアクティブ／パッシブ両対応の切り替え可能回路を目指す方針
- ステータスLEDの参照元をRaceCapture/Pro MK3に決定
- グラウンド設計：車載CAN(J6)・外部CAN(J4)のGNDが基板の共通GNDに直結されている実態を確認。対策は検討中
- IMUの実装方式（基板直付け／モジュール化）、磁力計とケーシングのアルミシールドの影響について論点整理

### 差分解析で確認できた変更点（tstamp基準でコンポーネント個体を追跡し、単なる部品番号振り直しと実質的な変更を区別済み）

**A. 既にARCHITECTURE.md 4章で確定済みの決定と整合する変更（想定通り）**
- GNSSモジュールを Teseo-LIV3FL → **MAX-M10M-00B** へ変更（同一シンボル個体の値変更として反映されている）。6e473c4の決定と一致
- GNSSバックアップ電池(BT1, CH004-2032LFホルダー)を完全撤去。d40fc54「GNSSバックアップ電源は非搭載」の決定と一致
- GNSSアンテナのアクティブ/パッシブ切替え回路（L1チョークコイルによるバイアスT、LNA_EN、VCC_RF）が新規追加。4章の「アクティブ/パッシブ切り替え可能回路を目指す」方針の具体化と見られる

**B. ARCHITECTURE.mdに未反映・友人への確認を推奨する変更**
1. **車載CAN(J4)・外部CAN(J5)のコネクタが JST VH → Molex Micro-Fit 3.0 (43045-0400, 2x2・4極) に変更されている。** ユーザー側メモでは外部CANはJST VH(4極)を仮採用しており、購入済み4芯ケーブル(AWG22/24混在)のAWG24芯線がVHの標準圧着端子（SVH-21T-P1.1等）の対応範囲外という懸念が未解決のまま残っていた。今回のMicro-Fit 3.0への変更がこの懸念を踏まえた意図的な変更なのか、友人が単に把握せず別コネクタを選定したのかは要確認。ハウジング形状も1x4→2x2に変わるため、購入済みケーブル・端子との適合性も要再確認
2. 車載CAN用トランシーバICが **MCP2562FD-E/P(DIP-8) → ATA6561-GAQW-N(SOIC-8)** に変更。機能上は同種の高速CANトランシーバで問題なさそうだが、ARCHITECTURE.mdの記載（3章の構成要素表）は旧型番のまま
3. **外部/車載CAN系統の5V供給ラインにあった保護ヒューズ F1・F2（Littelfuse LVR200S、2A保持型PTC）が削除**され、代替の保護素子も見当たらない。車体を這わせる外部ハーネス側の電源ラインから過電流保護が失われている可能性があり、意図的な簡略化か削除し忘れかを友人に確認することを推奨
4. USB Type-Cの役割判定・CC検出方式が、ディスクリートのアナログマルチプレクサ(CD74HC4053E)+抵抗分圧による自作回路から、**専用IC TUSB320IRWBR（Type-C CCロジックコントローラ）** を使う方式に刷新されている。関連する抵抗分圧網も再設計されている。望ましい簡素化・信頼性向上に見えるが未ドキュメント化
5. 3.3Vレギュレータが **LM2940T-3.3(TO-220, 1A定格) → BP5293-33(SIP3, 定格500mA程度)** に変更。ESP32-S3＋GNSS＋IMU＋CAN×2＋SDカード書き込みが重なるピーク電流が500mA以内に収まる想定か、友人側で検討済みか確認推奨
6. ほぼ全ての抵抗・電解/積層コンデンサがスルーホール(THT)からSMDフットプリントへ一括変換されている。量産・実装性向上として好ましい変化だが、電源平滑用コンデンサの一部は値も同時に変わっている（100u/1u系の混在 → 47u系へ整理など）ため、電源平滑設計の見直しとして意図的か確認要

**C. 軽微で確認不要と判断した変更**
- ステータスLED回路が単純なGPIO直結からシフトレジスタ(TC74HC595AF)+LED8灯構成に刷新。SER/SRCLKはCAN2用SPIバス(MCP25625T-E/SS)と共有だが、RCLK(ラッチ)・~OE・~SRCLRは独立配線されており設計上の問題は見当たらない。RaceCapture/Pro MK3参照方針と整合
- VBUS検出用分圧抵抗を5.1k/49.9k→49.9k/4.99kへ微調整（より標準的な10:1比へ）
- U2(LDR6321)のフットプリントをSSOP-16の正しいピッチへ修正（4.4x5.2mm→3.9x4.9mm）

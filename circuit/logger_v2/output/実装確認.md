# EcoLogger v2 Phase 1 回路図の実装確認

2026-09-07。受領した `refs/implementation_policy_received.md` と、作業開始時の logger_v2 回路図から作成。ユーザーの「元に戻して。すでにあったシンボルで、そのまま必要なものは消さないで動かさないで配線して」に従い、A3への再配置を取り消し、作業前のA4配置へ復元して配線。

## 完了範囲

- 回路図は元のA4・1枚。既存44部品をすべて残し、位置・向き・反転・UUID・シンボル定義・参照番号と値の表示位置を作業前と一致させた。既存の配線を保持し、主に元のローカルラベルの改名でUNO Qとの信号を接続。
- UNO Qヘッダから+5V・+3V3を受ける構成。VIN、BOOT、IOREF、RESET、AREF、アナログ端子は未使用。既存のヘッダと配線の位置を維持し、未使用端子は文字とNCで識別。
- 必要な既存電源シンボル35個も位置・向きを保持。未使用VINの誤ったVCCシンボルと、CAN1コネクタJ7 pin1の+5Vシンボルのみ削除。ERC用に外部供給電源のPWR_FLAGを3個追加。
- GNSS V_USBをGNDへ変更。VCC/V_BCKPは+3V3。bias-TはVCC_RF → R7 → バイアス点 → L1 → RF入力、C1はバイアス点からGND。
- C1は100nF/X7R/16V（値表示は100nF、詳細はSpecificationフィールド）、R7は22Ω・1W、CRCW251222R0FKEG、2512サイズ。L1は27nHを維持。部品の移動は行わず、GNSS電源とbias-Tの元の配線4区間だけを置き換え。
- R10、R13、R14をDNP。R10はLNA_ENの任意プルダウン用ランドを残すが、標準実装では開放。R13はCAN2のバス端に置く場合のみ実装。
- IMUのR15・R16（各4.7kΩ）は必要なプルアップとして実装。受領文書のDNP指定より、2026-09-07のユーザーによる訂正を優先。
- ローカルラベル38個の文字サイズを、このプロジェクトの標準値1.27mm（50mil）へ統一。部品の配置と既存の線分を保持し、文字の重なる箇所だけラベルの位置と引出し線を調整。
- CAN1 TXDは+3V3、STBYはGND。J7 pin1はNC。CAN2のTxCAN/TXD、RXD/RxCANの接続を維持。
- SPI2をCAN2と74HC595で共用。BNO055はD20/D21のI2C2。A4/A5のI2C3と分離。
- 44部品すべてにフットプリントと3Dモデルを登録。17種類のフットプリントと17個の実体STEPファイルをプロジェクト内へ保存。

## 受領資料から修正した端子割り当て

受領資料の「D3=FDCAN1_TX、D4=FDCAN1_RX」は、[Arduino公式フルピン配置図](https://docs.arduino.cc/resources/pinouts/ABX00162-full-pinout.pdf)（2026-02-17、1ページ）と一致しない。

公式図のD4/PA12=FDCAN1_TX、D5/PA11=FDCAN1_RXに従い、次のように接続した。

| 用途 | UNO Q | 回路図ヘッダ |
|---|---|---|
| CAN1_RXD | D5 / PA11 | J5.3 |
| GNSS_RESET_N | D3 / PB0 | J5.5 |
| FDCAN1_TX | D4 / PA12、未使用 | J5.4 / NC |

他は受領資料の割り当てを維持。D0=GNSS_TXD、D1=GNSS_RXD、D2=IMU_RESET_N、D6=GNSS_PPS（TIMEPULSE）、D7=STATUS_LATCH、D8=CAN2_RESET_N、D9=CAN2_INT_N、D10=CAN2_CS_N、D11/D12/D13=SPI2_MOSI/MISO/SCK。

## 検証結果

- KiCad 9.0.6 ERC: **エラー0・警告1**。警告はU1の元の74HC595定義と標準74xxライブラリとの不一致。作業前の回路図でも同じ警告が出ることを確認。シンボルをそのまま保持するため変更せず、ルール抑制も行っていない。
- 既存44部品と必要な電源35個の配置・向き・表示位置、元の全シンボル定義がバックアップと一致。
- 192物理端子について、出力ネットリストの端子間接続と設計した接続表が完全一致。元から直接配線されている回路の自動ネット名は維持し、名前ではなく同じネットに属する端子の集合を比較。未使用端子に意図しない接続なし。
- 全44部品でシンボル端子番号集合とフットプリントのパッド番号集合が一致。SMAのGNDパッドの重複番号も確認。
- 17モデルはすべてローカルSTEP実体。FreeCADで形状を読み込み、ソリッドと形状の有効性を確認。KiCadの3Dレンダリングでも全種類を表示。
- 元の `logger_v2.kicad_pcb` と `logger_v2.kicad_pro` は作業前とバイト単位で同一。`model_catalog.kicad_pcb` はモデル確認用の別基板で、製造・配置用ではない。

証跡: `validation.json`、`erc.json`、`original_erc.json`、`parts_and_models.csv`、`model_geometry_validation.json`、`model_catalog.png`。更新した回路図の表示は `logger_v2.pdf` と `logger_v2.png`、元の配置は `original_layout.pdf` と `original_layout.png`。

## 次工程へ引き継ぐ事項

### LNA_ENの10kΩ確認（2026-09-07）

NEO-M9NのLNA_ENは外付けLNA／アクティブアンテナのオン・オフ制御出力。メーカー資料UBX-19014286 R10の§4.3・Figure 31（71ページ）では未接続、§4.5.2・Figure 33（74ページ）のVCC_RF給電例でも10kΩは入っていない。現在のlogger_v2はVCC_RF → R7 → L1で給電し、LNA_ENに制御対象がないので、R10は実装不要と判断しDNPを維持する。シンボルとランドは削除していない。

MAX-M10Mについても、メーカー資料UBX-22038241 R02の§3.2.3.4（27ページ）は外付けLNA制御出力と説明し、Figure 36（85ページ）の標準3.3V回路ではLNA_ENは未接続。従って「MAX-M10Mでは10kΩが常に必須」とは言えない。外付けアンプやスイッチを接続する場合の抵抗は、その入力回路と起動・停止時の状態に応じて判断する。

出典: [NEO-M9Nメーカー資料](https://content.u-blox.com/sites/default/files/NEO-M9N_Integrationmanual_UBX-19014286.pdf)、[MAX-M10Mメーカー資料（販売店掲載）](https://www.mouser.com/pdfDocs/MAX-M10M_IntegrationManual_UBX-22038241.pdf)。確認用PDFと該当ページ画像は `refs/` に保存。

### PCB設計へ引き継ぐ内容

受領方針どおり、ICのパスコン・各電源のローカルバルク・GNSS RFの低容量ESD部品は今回追加していない。PCB設計時に追加し、発注前に回路図とBOMへ反映する。

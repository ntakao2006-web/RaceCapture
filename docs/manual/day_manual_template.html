0. 構成と連絡先

もの役目

1. 取り付けの確認（出走前・スイッチOFFのまま）

  1. 手元スイッチがOFFなのを確かめてから触る。
  2. 電源：高出力の口＝ロガー（ドック）。モニターは別の口。全部挿してからスイッチを入れる。
  3. ドックにカメラ・HDMI・電源。ドックは電源を入れる前につなぐ（動いている途中で差し替えると認識しない）。
  4. GNSS・LTEアンテナのコネクタを指で押し込む。シールドのSDが奥まで入っている。
  5. カメラの向き、ケーブルが走行の振動で引っ張られないか（手で揺する）。

2. 電源ON → 確認（毎回・エンジンを掛ける前）

  1. スイッチを入れる。電源を入れるだけで記録・録画が始まる（止めるボタンは無い）。
  2. 約1〜2分で車載画面が出る。隅の「記録・測位・送信」の印がそろえばよい（測位は空の見える所で。送信は最初の1回まで約2分）。
  3. エンジンを掛けると、回転数などの車の値が出る。
  4. ピットでは、スマホの表紙が「届いています」、またはPCのアプリの「いまの様子」が「すべて良好です」になれば、記録とLTEはOK。×が付いたら、横に出る直し方に従う。

録画は本体の空きが少なくなると、回収済みのものから古い順に自分で入れ替える。回収していないものは最後まで残すが、 残りが少ないとアプリが「あと約○分で消え始めます」と知らせる。その知らせが出たら、走る前に回収する。

3. 線（コントロールライン）の確認

  • 【このコースの線は設定済みか／現地で登録するか】。設定済みのコースでは、現地で登録し直すことは無い。
  • 公式の計測の線（路面の線・ビーコン）の位置を写真に撮る。少しずれていてもラップタイムは変わらない（ずれるのは1周目とピットに入った周の区切りだけ）。
  • 最初の数周で、車載画面の周が増え、前の周のタイムが出ること。出なければ7章。

4. 本番の前（ラップのリセット）

  1. 練習・予選のあと、本番の前にラップを0周に戻す：スマホの表紙の「操作」か、PCのアプリの「いまの様子」→「操作」→「ラップを0周に戻す」。
  2. 結果に「0周」と出るのを見る（ロガーから読み直した値）。線はそのまま、記録は止まらない。
  3. レース経過は、リセットのあと最初に線を通った時から数える。スタートの前に線を通るか：
  4. リセットできなくても走ってよい（周とレース経過が前からの続きになるだけ。前の周・ベストのタイムは正しい）。

5. 走っている間に見るところ

  • ドライバー：車載画面の印がそろっている、周が増えている。
  • ピット：表紙の値が動いている。「○秒前のまま」は電波の切れ目のことが多く、しばらくすると戻る。記録は本体で続いている。

値は車の設定（tools/setups/vehicles/<車>.json の dash の oil_warn・water_warn）から写す。すること（ペースを落とす・ピットへ、など）はチームで決めて書く。

6. 走り終えたら（止める）・回収

  1. スイッチを切る。記録・録画は電源OFFで閉じる（最後の約1秒が欠けるだけ）。
  2. （ピットのPC）ロガーの電源を完全に切ってからドックを外し、本体をPCとUSBで直結（PCから給電されて起動する）。
  3. PCでEcoLoggerアプリを開き、上の帯が「つながりました：USB」になったら、「回収」の段の「回収する」。
  4. 結果を読む：取れたもの／取れなかったもの／次にすること。「次にすること」が出たら、そのとおりにしてもう一度「回収する」（取れたものは取り直さない）。
  5. シールドのSD：USBを抜いて電源を切り、SDを抜いてPCのカードリーダーへ → もう一度「回収する」。
  6. 回収しても、本体からは消えない（本体が空きの要るときに、回収済みから自分で入れ替える）。

7. 困ったとき

症状まずやること
どこが悪いか分からないPCのアプリの「いまの様子」。×の横に直し方が出る。つながらないときは、USB・テザリングそれぞれの理由が出る
車載画面が「信号なし」2分待つ（ロガーが自動で出し直す）。だめならHDMIを抜き差し
画面が止まった・消えた走ってよい。電源が落ちていることがある。戻れば記録・録画は自動で再開（ファイルが分かれるだけ）。戻らなければピットで電源・ドックの差し込みを確かめ、スイッチを入れ直す。起きた時刻をロガー担当へ
車の値が出ないエンジンが掛かっているか。車のCANの線（OBD2のタップ）が外れていないか
周が増えない・前の周が出ないタイムは公式が正。ピットでロガー担当へ（線の位置・向き）
ピットの表紙に値が出ない記録には影響しない。測位待ち・電波。起動から最初の送信まで約2分
表紙から操作を送れない合言葉（PCのアプリのQRを読み直す）。「返事がありません」は、届いたか分からないので「状態を聞く」で確かめる
回収で本体の分が取れない結果の「次にすること」。電源が入ったままドック⇔PCを差し替えない（電源を完全に切ってから）

それでも分からないとき：docs/manual/ecologger_troubleshooting.html（ロガー担当向け）。

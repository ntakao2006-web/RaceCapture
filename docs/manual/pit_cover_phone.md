# ピットの表紙をスマホで使う（開く・ホーム画面に置く・合言葉を入れる）

2026-11-13 作成（SP-6-4）。ピットの表紙は、スマホで開く入口のページ（自宅のサーバーにある。ロガーの値はLTEで届く）。
**見るだけなら合言葉は要らない。** ロガーへ操作を送る係の人だけ、合言葉を入れる。

> このリポジトリは公開なので、ページのアドレスはここに書いていない。アドレスはロガー担当から受け取る。
> この手順のうち、実物のスマホで確かめていない所には「未確認」と書いてある。

## 1. 開く

1. ロガー担当から受け取ったアドレスを、スマホのブラウザ（AndroidはChrome、iPhoneはSafari）で開く。
2. いちばん上の帯を見る。
   - 「届いています（○秒前）」… ロガーの値が届いている
   - 「○秒前のまま」… 値が止まっている（数字が薄くなる）。電波の切れ目なら、しばらくすると戻る
   - 「ロガーを待っています」… まだ1回も届いていない（電源・LTE）
3. 下の行き先から、地図・周回表（エコランは時計）・G-Gを開ける。

## 2. ホーム画面に置く

毎回アドレスを入れなくて済むように、アイコンを置いておく。

- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」→「追加」。
- **iPhone（Safari）**：下の「共有」（四角から矢印が出ている印）→「ホーム画面に追加」→「追加」。

置いたアイコンから開いて、1章と同じ帯が出れば終わり。

## 3. 合言葉を入れる（操作を送る係の人だけ）

合言葉は、PCと本体だけが知っている鍵。入れたスマホからは、ラップのリセットなどの命令をLTEで送れる。

1. PCで **EcoLoggerアプリ** を開き、「いまの様子」→「操作」→「ほかの操作・合言葉」→ **「スマホへ合言葉を渡す（QR）」** を押す。
2. 出てきたQRを、スマホのカメラで読む。表紙が開き、合言葉が入る。
3. ロガーが動いていれば、その場で「合言葉が合っていました」と出て、スマホが覚える。
   ロガーが動いていないときは「いまは確かめられません」と出るので、「確かめずに覚える」を選ぶ（次に操作を送ったときに確かめられる）。

注意：

- **QRには合言葉そのものが入っている。** 写真に撮って送ったり、画面を共有・配信したりしない。QRは2分で消える。
- 合言葉は、そのスマホの、そのブラウザの中にだけ覚える（サーバーには置かない）。ブラウザの閲覧データを消すと、合言葉も消える。
- **iPhoneでホーム画面のアイコンから開いたとき**は、Safariで覚えた合言葉が見えないことがある（アイコンから開いたページは、覚える場所がSafariと別になることがあるため。**未確認**）。そのときは、アイコンから開いた画面の「操作」の欄に、合言葉を手で入れる。
- スマホを無くした・渡しすぎたときは、PCのアプリの「合言葉を作り直す」（本体をつないで）。前に渡したスマホは、QRを読み直すまで送れなくなる。
- 合言葉を消すときは、表紙の「操作」の欄の「合言葉をこの機器から消す」。

## 4. 操作を送る

「操作」の欄から、状態を聞く・ラップを0周に戻す・周回数を直す・いまから計測を始める・記録を始める、を送れる。

- 送ると、ロガーの返事を待つ（数秒。最大30秒）。「届きました」と、ロガーのいまの様子が出る。
- 「返事がありません」は、届いたかどうか分からない、という意味。届いて効いていることもあるので、「状態を聞く」で確かめる。
- 車が走っているとき（5 km/h以上）は、画面に出た4桁の数字を入れてから送る（押し間違いを防ぐため）。

## 5. うまくいかないとき

| 見え方 | すること |
|---|---|
| ページが開かない | スマホがインターネットにつながっているか。アドレスの打ち間違い |
| 「合言葉が違います」 | PCで合言葉を作り直していないか。QRを読み直す |
| 「この開き方では送れません」 | アドレスが `https://` で始まっているか（`http://` では送れない） |
| 「返事がありません」が続く | ロガーの電源・LTE。PCのアプリの「いまの様子」で、LTEが○かを見る |
| 値が「○秒前のまま」のまま戻らない | 同上。走行の記録は、画面と関係なく本体で続いている |

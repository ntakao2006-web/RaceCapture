# Podium送信の自動切替（Wi-Fi⇔LTE）実機試験計画（ER-1-6）

> 2026-10-15作成。**大会中にピットへ数値を届ける唯一の経路**なので、PCの試験だけで本番に使わない。
> この計画の試験を全部通したときだけ、本番の設定を「自動」にする。1つでも通らなければ**本番は「LTEだけ」**にする。

## 何を確かめたいか

本番の流れは「ピット（スマホのテザリングでWi-Fi）→ コースへ出る（Wi-Fiが切れる）→ 走行中（LTE）→ ピットへ戻る」。
確かめるのは次の3つ。

1. Wi-Fiが切れたら、**必ずLTEに移る**（止まったままにならない）
2. 移るまでに**何秒途切れるか**（Podiumの画面が止まって見える時間）
3. 走行中に**LTEから余計に切り替わらない**（行ったり来たりしない）

## PCで確かめ済みのこと（2026-10-15）

- 「自動」の選び方：Wi-Fiがつながっていれば Wi-Fi、切れていれば LTE、状態が読めなければまず Wi-Fi を試す
- Wi-Fiで送信中に「切れた」と読めたら送信をやめ、待ち時間なしで LTE へ移る。その後30秒は Wi-Fi を試さない
- Wi-Fiの状態が2回続けて読めなければ「切れた」とみなす（LTEなら困らないので安全側）
- Wi-Fiの接続は8秒で見切る（テザリングにつながっていてもネットに出られない場合）
- NetworkManagerの状態の読み方（`100 (connected)`、書式が違えばIPアドレスの有無）
- 切替の記録（`/api/podium/events`）

## PCでは確かめられないこと（実機で確かめる）

- Wi-Fiの状態を、UNO Qの管理サービスから本当に読めるか
- `TCP_USER_TIMEOUT`（送ったデータに5秒返事が無ければ切断）がUNO Qで効くか。電波が弱くなって、つながったまま通らない状態のときに効く
- LTEへの接続にかかる時間（モデムの登録・通信開始のやり直し）
- 長時間・繰り返しでの安定性

## 準備

- UNO Q（最新版を反映済み）、LTEアンテナとSIM、GNSSアンテナ（屋外か窓際で測位させる。測位しないとPodiumに出ない）
- スマホ（テザリング）、PC（UNO QとUSBでつなぎ、`http://127.0.0.1:8080/api/podium/events` と状態を見る）
- Podiumの画面（`app.podium.live`）を別の端末で開いておく
- 設定：Podium送信「自動」、送信先は本番と同じ（直接か中継サーバーか）

## 記録のとり方

- `/api/podium/events` に、切替ごとに次の記録が残る：`session_start`（どちらの経路で始めたか）、`first_frame`（最初に送れた時刻）、`session_end`（終わった理由・最後に送ってからの秒数）
- **途切れた時間 ＝ LTEの `first_frame` の時刻 −（Wi-Fiの `session_end` の時刻 − その `last_sent_age_s`）**
- Podiumの画面でも、数値が止まって見えた時間をストップウォッチで測って、記録と合うか見る

## 試験

| No. | 何をするか | 回数 | 合格の条件 |
|---|---|---|---|
| A-1 | Wi-Fiに何もつながない状態で電源を入れる | 2 | 最初から LTE で送る。Podiumに出る |
| A-2 | テザリングにつないで電源を入れる | 2 | Wi-Fi で送る。画面に「自動：今はWi-Fi」と出る。Podiumに出る |
| B-1 | Wi-Fiで送信中に**スマホのテザリングをOFF**にする | 5 | 毎回 LTE に移る。途切れた時間を記録する |
| B-2 | Wi-Fiで送信中に、**UNO Qを持ってスマホから歩いて離れる**（電波が弱くなってから切れる。本番のピット出口に近い） | 5 | 毎回 LTE に移る。途切れた時間を記録する。**本番を一番よく再現する試験** |
| B-3 | テザリングはつながったまま、**スマホのモバイルデータをOFF**（Wi-Fiはあるがネットに出られない） | 3 | LTE に移る |
| B-4 | Wi-Fiで送信中に、UNO Qの管理サービスを止める（状態が読めない） | 2 | LTE に移る。終わったら管理サービスを戻す |
| C-1 | LTEで送れている間にテザリングを戻す | 3 | **LTE のまま変わらない**（行ったり来たりしない） |
| C-2 | テザリングOFF⇔ONを1分おきに繰り返す | 10往復 | 毎回どちらかで送れている。止まったままにならない |
| D-1 | 「自動」のまま LTE で連続送信 | 60分 | 再接続が増え続けない。Podiumに出続ける |
| D-2 | 試験中ずっと記録（CSV）を回しておく | 全体 | 切替の前後でCSVの行が途切れない（送信の切替が記録に影響しない） |

## 判定

- **全部合格**：本番は「自動」。途切れた時間（B-1・B-2の最大）を手順書に書き、ピットに「出走直後は数十秒止まって見えることがある」と伝える
- **B-2の途切れが長い（目安60秒超）**：対策を検討（LTEを裏で先につないでおく等）。大会までに直らなければ本番は「LTEだけ」
- **1つでも「LTEに移らない」**：本番は「LTEだけ」。「自動」はピットでの確認用にだけ使う

# Lintarohさんへの相談：SUGO 120分耐久（11/8）でロードスターの油温・油圧を読みたい（2026-10-25）

エコラン大会ではありがとうございました。次は**11/8（日）のSUGO 120分耐久**に、ロードスター（NCEC）で出ます。
ロガーはエコランで使ったVer.2（UNO Q）をロードスターへ載せ替える予定です。
**11/7の朝に出発するので、車に付けられるのは実質11/3〜4まで**です。

そこで、**油温・油圧をロガーへ取り込む基板を、それまでに用意できる形があるか**を相談させてください。
部品・回路・方式の判断はLintarohさんにお任せします。

## 1. 前提

- 油温・油圧は**マツダスピード3連メーター（Defi製）がすでに付いていて、ドライバーは見られます**。
  なので今回の基板は「無いと走れないもの」ではなく、**記録とピットでの監視・警告のため**です。**間に合わなければ大会後で大丈夫です**
- 設計書は`sensorhub_defi_tap_design.md`（v2：油温はサーミスタを切り離して直接測り、デジタルポテンショメータでDefiへ同じ抵抗値を見せる／油圧は分圧で横から覗く）です。
  ただ、回路図入力・基板レイアウトがまだなので、**JLCPCBの基板はSUGOに間に合わない**と見ています
- ロガー側は、エコラン用に作った「センサーハブの油温」の受信（CAN2、ID 0x500、2–3バイト目＝5Vに対する比率、リトルエンディアン、10Hz）がそのまま使えます。
  送り方が違っても、教えてもらえればロガー側を合わせます

## 2. 相談したいこと

| # | 内容 | こちらの考え（叩き台） |
|---|---|---|
| 1 | エコラン用に話していた**ユニバーサル基板版のハブ**は、その後どうなりましたか | もしあれば、まずそれを流用できないか |
| 2 | **11/3までに車に付けられる形はありそうですか** | ユニバーサル基板でかまいません。見込みを**10/28（水）ごろまで**に教えてもらえると、大会の段取りを決められます |
| 3 | 両方が難しければ**油圧だけ先に**できますか | 油圧センサーは電圧出力なので、設計書では分圧で横から覗くだけにしています。油温は水温＋10℃で代用できる（純正の水冷オイルクーラーで連動している）ので、後回しにできます |
| 4 | 油温を簡易な方法で読むとしたら、どういう形が良いですか | v2の「切り離して再現」は手間がかかるので、SUGO向けにもっと簡単な方法があれば知りたいです（Defiの表示に影響しないことが条件です） |

## 3. こちらでやること

- **10/27〜28にオイル交換で車をいじるので、そのときにDefiセンサーの型番・配線を確認します**（`ncec_next_session_checklist.md`の項目G：刻印の写真、ピン数、
  油圧センサーの赤・白の電圧、**油温センサーのGND側と油圧の黒が導通しているか**、油温の信号線をどこで切れるか）。結果はすぐ共有します
- ロガー側の受信・換算・表示は、ハブの形が決まり次第こちらで合わせます

## 4. ついでの共有（急ぎではありません）

- ロードスターでは車載CAN（CAN1、約680フレーム/秒）をつなぐので、**全フレームをLinuxへ渡している分、LTEの送信が約1.25フレーム/秒に落ちます**（10/19に実車で確認、`EcoCapture-Web/LTE_PODIUM.md`）。
  ピットで温度を見るだけなら1秒に1回で足りるので、**SUGOはこのままで行くつもり**です。STM32側で「設定済みの信号のID（NCECなら0x201・0x4B0・0x240・0x420・0x430）だけLinuxへ渡す」改修は、大会後に相談させてください

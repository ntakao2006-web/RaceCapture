# Lintarohさんへの相談：車の12V側に入れる小さなUPSを作ってもらえますか（2026-11-13）

Ver.2（UNO Q）の電源を、モバイルバッテリーから**車の電源（ヒューズ電源）へ直接**に変えたいと考えています。
そのとき、**ヒューズ電源とシガーソケットの充電器の間**に、数秒だけ電気を保つ小さなUPSを入れたいです。
合う市販品が見つからなかったので、作ってもらえるか相談させてください。
部品・回路・方式の判断はLintarohさんにお任せします。

**次に使うのは12月5日です。車に付けて確かめる日を見て、その3〜4日前（12月1日〜2日ごろ）までにほしいです。**
難しそうなら、早めに教えてください。

11/5のメモ（`lintaroh_share_20261105_dock_power.md`）の続きです。あちらの「ドックをUPSの内側に入れる案」は、
UPSがシールドとして積んであるので取り回しが難しそうだ、と考え直しました。それでUPSを置く場所を12V側へ移す案です。

## 1. 入れたい場所

```
ヒューズ電源 → 手元スイッチ → 【ここに入れたい】 → 増設シガーソケット → 車用充電器（アドテック ACPD-V100AC）
                                                      ├─ USB-C（PD、同時使用時65W）→ ドックのPD給電口 → UNO Q・カメラ・HDMI
                                                      └─ USB-A（QC3.0、18W）→ QCトリガーケーブル12V → モニター（HD7H）
UNO Q ＋ UPSモジュール ＋ シールド（今のまま積み重ね）
```

- 手元スイッチより後ろに置きたいです。スイッチを切ったら数秒で全部が止まる形にするためです
- 充電器はアドテックにします。分解できた実績があるためです（中に組み込む形でも、外に箱を足す形でも構いません）

## 2. なぜ要るか

- 充電器の出力が一瞬切れると、UNO QはUPSモジュールで動き続けますが、**ドックだけが落ち、モニターとカメラがLinuxの再起動まで戻りません**（11/5のメモの2章）
- 車から直接取ると、エンジン始動時の電圧低下や、プラグ・端子の接触で一瞬切れることがありえます。走る時間が長いほど当たる見込みが上がるので、運用で避けるのではなく、切れない形にしたいです
- 12V側で保てば、充電器・ドック・モニターをまとめて守れ、USB PDのやり取りのやり直しも起きません

## 3. ほしいこと

| # | 項目 | ほしい姿 | 備考 |
|---|---|---|---|
| 1 | 保つ時間 | **数秒**（長くても10秒ほど） | 一瞬の停電と始動時の電圧低下を越えられれば足ります。長く保つと、スイッチを切っても止まらず困ります |
| 2 | 保つ相手 | 充電器の入力（12V） | 充電器の先は、ロガー一式（UNO Q・シールド・LTE・ドック・カメラ）とモニター（最大約10W）。**全体の消費は測っていません**。必要なら測ります |
| 3 | ためる部品 | リチウム電池は避けたい | 夏の車内に置きっぱなしにするためです。スーパーキャパシターなどを想像していますが、お任せします |
| 4 | スイッチを切ったとき | 数秒〜十数秒で出力が止まる | 「電源のON/OFF＝記録の開始・終了」の考え方に合わせたいです |
| 5 | 電源を入れたとき | すぐ出力が出る | ためる部品の充電を待たずに動き始めてほしいです。充電の電流でヒューズが飛ばないようにもしたいです（どの回路・何Aから取ったかは記録していないので、こちらで確かめます） |
| 6 | 車の電源への耐性 | エンジン始動時の低下、走行中の約14V、瞬間的な高い電圧 | |

## 4. あわせて聞きたいこと

1. **今のUPSモジュール（シールド）は残すべきですか。** 12V側にUPSが入れば外してもよいのでは、とも考えています。
   ただ、急に電源が切れたときに記録を守っているのは今のUPSだと理解しているので、判断をお願いします
2. **今のUPSモジュールは、電源を切ってから止まるまでが長い**です（体感で2分ほど。測ってはいません）。
   10/9のメモでは「約10秒保持」と理解していました。残す場合、これを短くできますか（11/5のメモの3章 4〜6と同じ話です）
3. 11/5のメモの3章 1（今のUNO QとUPSモジュールの給電経路）は、引き続き教えてほしいです

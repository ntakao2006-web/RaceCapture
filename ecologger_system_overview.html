EcoLoggerの全体像（エコラン大会 2026-10 時点）

車で測る → LTEでサーバーへ → ピットで見る・話す ／ 記録は必ず車の中に残る

つながり

車・現地の機材 インターネット上 ピット 保険（ふだんは使わない） 点線の矢印：必要なときだけ

覚えておくこと

  • 記録は車の中で完結する。Ver.2はmicroSDと本体(eMMC)の2か所、Ver.1とスマホもそれぞれ本体に記録する。LTE・サーバー・ピット画面が止まっても、記録は止まらない。
  • ピット画面は「見るためのもの」。車 → LTE → 中継サーバー → ブラウザ、と届くので、数秒（多いと10秒近く）遅れる。トンネルや山陰で一時的に途切れても、自動でつなぎ直す。
  • 電源ONから最初にピットに出るまで約1分半〜2分（UNO Qの起動とLTEの接続）。その間は電源を抜かない。
  • ラップの基準はVer.2の1か所。コースウォークでVer.2に3本のライン（スタート・コントロール・ゴール）を登録し、スマホ2台はQRで同じラインを受け取る。
  • 音声は記録・テレメトリより下。LTEが混んだら音声が先に止まる作り。音声を切ってもピット画面は変わらない。
  • 通信量：Ver.2のテレメトリで1時間あたり約4MB。SIMは上限を超えると従量課金（止まらない）。

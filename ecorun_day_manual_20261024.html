1. 取り付け（走る前・電源OFFのまま）

  1. SDカードがVer.2・Ver.1の両方に奥まで入っているか。
  2. GNSS・LTEアンテナは空が見える向き。コネクタを指で押し込む。
  3. Ver.2：UNO Q ← ドック（USB-C）。ドックに電源とUSBオーディオ（ドライバーのイヤホン・マイク）。
  4. ケースを固定し、走行の振動でケーブルが引っ張られないか手で揺すって確かめる。
  5. スマホ組：アプリの電池の最適化を「制限なし」に。モバイルバッテリーをつなぐ。端末の向き：

2. 電源ON → 記録の確認（毎回）

Ver.2・Ver.1は電源を入れるだけで記録が始まる。ボタン操作は要らない。

  • Ver.2：スマホのテザリングにつないで uno-q.local:8080 を開く。 上部が 「● REC」 ならOK。「● REC（本体のみ）」はSD不調（本体には記録中）→ 電源を入れ直す。
  • Ver.1：LOGランプ点灯＝SD記録中。GPS点灯＝測位済み（点滅は未測位）。ERR点灯は異常。
  • スマホ組：アプリで「記録を始める」。常駐の通知が出ていれば画面を消してよい。
  • ピット画面に3台の位置・速度が出るか確認（出なくても記録は本体に残る）。

3. コースウォーク（10/24朝・Ver.2のラップ）

  1. Ver.2を手持ち電源で持ち、スマホのテザリングにつなぐ。スマホでブックマークしたコースウォーク画面を開き、「測位OK」になるまで待つ。
  2. 各ラインの真上に立って止まり「ここを〇〇にする」：コントロール（必須）、スタート・ゴール（別の場所なら）。直前3秒の位置を平均して登録する。
  3. 規定周回数：周のボタンを押す（四輪7周・二輪3周）。
  4. スマホ組は、画面下の「QRを表示」をEcoLoggerアプリで読む。全台の「基準」の番号がそろっているか見る。
  5. レース開始前に「周回数をリセット」を押す（押さないと前の続きから数える）。

4. 走り終えたら（止める）

  1. Ver.2：Web画面の「記録停止」→ 電源OFF。
    画面が開けないときは、そのまま電源OFFしてよい（本体の記録は最後の約1秒が欠けるだけ）。
  2. Ver.1：PCをUSBでつなぎ SD_Eject.cmd を実行 → safeToRemove: true が出てから電源OFF。
    エラー・タイムアウトなら抜かない（もう一度実行）。
  3. スマホ組：アプリで「記録を止める」。
  4. 電源OFFを確認してからSDを抜く。記録中にSDを抜かない。

5. 回収（ピットのPC・走行ごとに）

  1. 抜いたSD（Ver.1・Ver.2）をカードリーダーでPCへ。2枚同時でよい。
  2. UNO QをPCとUSBで直結（ドックから外す）。または同じテザリングにつなぐ。
  3. スマホをUSBでつなぎ、通知から「ファイル転送」を選ぶ。
  4. Collect-Logs.cmd（RaceCapture\tools\collect_logs\）をダブルクリック。
  5. 最後に「新しいログ ○件を回収しました」と出ればOK。drive_logs\日付\runNN_時刻\ に入る。
    元のファイルは消えない。何度実行しても同じものは二度取らない。UNO Qが起動直後に作る「記録中」の1件は取らないのが正常。
  6. 回収できたらSDを戻す（消去・フォーマットはしない）。

6. 困ったとき

症状まずやること
uno-q.local が開けないUNO Qとスマホが同じテザリングか確認。だめならUSBでPCにつなぐ。記録は画面と無関係に続いている
「REC（本体のみ）」電源を入れ直す。直らなくても本体に記録中なので走ってよい
ピット画面に出ない予備URLへ切り替えて見る。記録には影響しない
Ver.1 ERR点灯電源入れ直し。Ver.2が記録中なら走行を優先
回収で「UNO Qに接続できません」USBケーブル・電源を確認して再実行（SD分は回収済み）
回収で「スマホのログは見つかりません」USBを「ファイル転送」に。だめならエクスプローラーで内部共有ストレージ\Download\EcoLoggerをPCへコピー

1. 取り付け（走る前・電源OFFのまま）

  1. SDカードがVer.2・Ver.1の両方に奥まで入っているか。
  2. GNSS・LTEアンテナは空が見える向き。コネクタを指で押し込む。
  3. Ver.2：UNO QのUSB-Cに電源（音声機器はつながない）。
  4. ケースを固定し、走行の振動でケーブルが引っ張られないか手で揺すって確かめる。
  5. 表示用スマホ：ホルダーに横向きで固定し充電ケーブルをつなぐ。直射日光の当たる所は避ける（熱で暗くなる・止まる）。有線イヤホンを挿す。
  6. スマホ組：アプリの電池の最適化を「制限なし」に。モバイルバッテリーをつなぐ。端末の向き：

2. 電源ON → 記録の確認（毎回）

順番：ロガー（Ver.2）→ 約2分待つ → 表示用スマホ。Ver.2・Ver.1は電源を入れるだけで記録が始まる。

  • Ver.2：表示用スマホの上の2つ目の欄が緑の「ロガー 3D …衛星」なら動いている。記録中かはピット画面に位置・速度が出るかで見る（PCがあれば管理画面の上部が「● REC」。「本体のみ」はSD不調→電源を入れ直す）。
  • Ver.1：LOGランプ点灯＝SD記録中。GPS点灯＝測位済み（点滅は未測位）。ERR点灯は異常。
  • 表示用スマホ：EcoLoggerで「記録を始める」。初回だけ「デバイスに接続」が出たら「接続」。見出しのクラスが車のクラス（）か見る。黄色の「スマホ」と赤い帯「ロガー未接続」なら6章。
  • スマホ組：アプリで「記録を始める」。常駐の通知が出ていれば画面を消してよい。

3. コースウォーク（10/24朝・PCと管理画面）

  1. （ロガー担当）UNO Qを電源を入れる前にPCへUSBでつなぐ（電源もPCから）→ 約2分 → PowerShellで下のコマンド → ブラウザで http://127.0.0.1:8080/ → 設定 →「ラップ計測」。
    & "$env:LOCALAPPDATA\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Local\Android\Sdk\platform-tools\adb.exe" -s 2954148814 forward tcp:8080 tcp:8080
  2. USBのまま Start-RadioWalk.cmd（tools\lte_antenna\）→「電波の記録を始めました」（30分で自動停止。だめなら省いてよい）。
  3. UNO QとPCを持って歩き、各ラインの真上で止まって「現在地をこのラインにする」：コントロール（必須）・スタート・ゴール。直前3秒の平均で登録。向き・規定周回数は入れない（向きはレースの最初の通過で覚え、規定周回数は表示用スマホから入る）。
  4. スマホ組は管理画面の「ラインをスマホへ」のQRをEcoLoggerで読む。
  5. 歩き終えたら Fetch-RadioWalk.cmd → USBを外す（ラインは保存されている）。

3b. グリッドで（スタート直前）

  1. グリッドへ移動してから、表示用スマホの 設定 →「ラップをリセット」→「ロガーの周回もリセットしました」と出ること（出なければUSBの管理画面で「周回数をリセット」）。スマホ組は各アプリで。
  2. 見出しが「クラス・エコラン式　基準XXXX」、周回が「0 / 規定周回　スタート前　ロガー 0周」になること（リセット前は前の走行が残り、ラインがそろわない）。
  3. スタート後、ピット画面の周回「走行中」が1になること（0のままならロガーがスタートを取りこぼした）。

3c. ピット画面の時計の確認（毎回・ピット）

  1. （スタート前）「スタート前」、規定まで＝規定時間（）。「規定時間なし」なら表示用スマホ・アプリの設定「大会」を見直す。「この画面のデータ」が10秒以内（赤＝回線が詰まっている）。
  2. 合図でストップウォッチを押す（タイムはこちらが正）。2〜3分後と以後10分ごとに「画面の経過−ストップウォッチ」： 秒。差が3秒以上広がる・秒が止まるなら6章（最初からの数秒のずれは問題ない）。

4. 走り終えたら（止める）

  1. Ver.2：そのまま電源OFFしてよい（本体の記録は最後の約1秒が欠けるだけ）。
  2. Ver.1：PCをUSBでつなぎ SD_Eject.cmd を実行 → safeToRemove: true が出てから電源OFF。
    エラー・タイムアウトなら抜かない（もう一度実行）。
  3. 表示用スマホ・スマホ組：アプリの「長押しで停止」。
  4. 電源OFFを確認してからSDを抜く。記録中にSDを抜かない。

5. 回収（ピットのPC・走行ごとに）

  1. 抜いたSD（Ver.1・Ver.2）をカードリーダーでPCへ。2枚同時でよい。
  2. UNO QをPCとUSBで直結（電源もPCから取れる）。
  3. スマホをUSBでつなぎ、通知から「ファイル転送」を選ぶ。
  4. Collect-Logs.cmd（RaceCapture\tools\collect_logs\）をダブルクリック。
  5. 最後に「新しいログ ○件を回収しました」と出ればOK。drive_logs\日付\runNN_時刻\ に入る。
    元のファイルは消えない。何度実行しても同じものは二度取らない。UNO Qが起動直後に作る「記録中」の1件は取らないのが正常。
  6. 回収できたらSDを戻す（消去・フォーマットはしない）。

6. 困ったとき

症状まずやること
表示用スマホに赤い帯「ロガー未接続」走ってよい（スマホのGNSSで周回・速度を続ける。精度は落ちる）。ピットで：ロガーの電源→起動後2分待つ→アプリを止めて始め直す。帯の（ ）内が理由。ロガーが戻れば自動で緑の「ロガー」に戻る
「デバイスに接続」が出た／「見つかりません」「接続」を押す。見つからなければロガーの電源と、起動から2分たったかを確認
「ロガー未接続」で（Binding…EPERM）スマホのVPN（Tailscale等）をOFFにするか、VPNアプリでEcoLoggerを除外
PCで管理画面が開けない（adbが offline）UNO Qの電源を完全に切る（UPSの電池も外す）→ PCにつないでから電源を入れ直す。電源が入ったままUSBをつなぎ直さない
「本体のみ」電源を入れ直す。直らなくても本体に記録中なので走ってよい
ピット画面に出ない記録には影響しない。Ver.2の起動から最初の送信まで約1分40秒かかる
ピットの時計がずれていく・止まるストップウォッチを正としてドライバーへ。ページを開き直し、ずれた秒数・時刻をロガー担当へ。赤「n秒前のまま」だけなら時計は進むので見てよい
Ver.1 ERR点灯電源入れ直し。Ver.2が記録中なら走行を優先
回収で「UNO Qに接続できません」USBケーブル・電源を確認して再実行（SD分は回収済み）
回収で「スマホのログは見つかりません」USBを「ファイル転送」に。だめならエクスプローラーで内部共有ストレージ\Download\EcoLoggerをPCへコピー
RadioWalkで「接続できません」UNO QとPCのUSBを確認。だめなら省いてよい（ライン・記録に影響なし）
【要確認】と出た表示をスマホで撮影してロガー担当へ。SD・本体のファイルは消さずに保管

7. 通話（Discord・表示用スマホ）

  • Discordは表示用スマホのLTEで使う（ロガーのWi-FiはEcoLoggerだけが使うので邪魔しない）。
  • ドライバー：有線イヤホンで聞く。話すのは「音声検出」＋ノイズ抑制ON。走行音で送りっぱなしになるなら感度を上げる（出走前に車内で確かめる）。
  • ピット：「プッシュ・トゥ・トーク」で話す（押している間だけ）。

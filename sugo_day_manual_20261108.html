1. 取り付けの確認（出走前・スイッチOFFのまま）

  1. 手元スイッチの蓋が開いている＝OFFを確かめてから触る。
  2. 充電器の2口：高出力側＝ロガー（ドック）、もう一方＝モニター（9Vのケーブル）。2口とも挿してからスイッチを入れる。
  3. ドックにカメラ・HDMI・電源。ドックは電源を入れる前につなぐ（動いている途中で差し替えると認識しない）。
  4. GNSS・LTEアンテナのコネクタを指で押し込む。シールドのSDが奥まで入っている。
  5. カメラの向き、ケーブルが走行の振動で引っ張られないか（手で揺する）。

2. 電源ON（毎回・エンジンを掛ける前）

録画は1回の電源ONで約2時間45分まで（それを超えると録画が止まる。走行記録は続く）。 予選のあとは一度スイッチを切り、決勝の電源はスタートの45分前より後（9:45以降、目安10:00）に入れる。朝から入れっぱなしにしない。

  1. レバーを上げて蓋を閉じる（蓋が閉まっている＝ON）。電源を入れるだけで記録・録画が始まる（止めるボタンは無い）。
  2. 約1〜2分でモニターに「SUGO 120min」。時刻（Utc）が進んでいれば本体は動いている。
  3. エンジンを掛けると水温・回転数が出る。油温は基板がつながっていれば出る。
  4. ピット画面に位置・速度が出れば、記録とLTEはOK（GNSSが測位するまで出ない。最初の送信まで約1分40秒）。

3. ラインの確認（朝のコースウォーク）

  • ロガーのラインは設定済み（グランドスタンド前、メインストレートとピットレーンをまたぐ幅50m）。現地で登録し直すことは無い。
  • 公式の計測ライン（路面の線）の位置を写真に撮るだけ。ずれていてもラップタイムは変わらない（ずれるのは1周目とピットに入った周の区切りだけ）。
  • 予選の最初の数周で、モニターの周（CurrentLap）が増え、前周（LapTime）が出ること。出なければ7章。

4. 予選のあと・決勝の前（ラップのリセット）

  1. 予選から戻ったらスイッチを入れたまま、パドックでPCとPixel（テザリング）を車の近くへ。
  2. PCで Reset-Laps.cmd（RaceCapture\tools\sugo_setup\）→「ラップの記録を消しました（完了0周）」。
    ラインはそのまま。「★ラインが…」と出たらロガー担当へ。
  3. スイッチを切る（決勝の録画の時間を残すため）。決勝の電源は2章の時刻から。
  4. レース経過（SessionTime）は、リセットのあと最初にラインを通った時から数える。 スタートまでにラインを通る（ピットからグリッドへ・フォーメーションラップ）とそこから数える： （t970の公式通知で分かったら書く）
  5. リセットできなくても走ってよい（レース経過と周が予選からの続きになるだけ。前周・ベストのタイムは正しい）。

5. ドライバー交代のときに見るところ

  • スイッチの蓋が閉まっている。モニターの時刻が進み、周が増えている。
  • 給油（第1ゲートから外のスタンド）の周は長くなる。ロガーは何もしなくてよい。

6. 走り終えたら（止める）・回収

  1. 蓋を開けてレバーを倒す。蓋は開けたまま（開いている＝OFF）。記録・録画は電源OFFで閉じる（最後の約1秒が欠けるだけ）。
  2. （1日の最後・ピットのPC）ロガーの電源を完全に切ってからドックを外し、UNO QをPCとUSBで直結（PCから給電されて起動する）。シールドのSDはカードリーダーでPCへ。
  3. 約2分待って Collect-Logs.cmd（RaceCapture\tools\collect_logs\）。動画も吸い出す（120分で約11GB、約5分）。
  4. 「新しいログ ○件を回収しました」→ drive_logs\日付\runNN_時刻\（v2_emmc・v2_video・v2_sd）。元のファイルは消えない。
  5. 回収するまでロガーを長く動かさない（空きが足りなくなると、前の電源ONの動画から古い順に消える）。
